Privacy Policy

Last updated: July 3, 2026

BridgeBot is designed with privacy in mind. We collect only what is strictly necessary to operate the bot. We do not sell, share, or monetize any data.

1. What We Collect

DataWhy We Collect ItStored?
Server IDTo identify your server's configurationYes
Channel IDsTo know which channels are bridgedYes
User ID (of admins)To record who created/deleted bridges (audit log)Yes
Message metadataTo prevent relay loops (original + relayed message IDs, stored 30 days)30 days
Message contentRelayed in real-time — not storedNo
Usernames / avatarsUsed in-memory during relay — not storedNo

2. What We Do NOT Collect

  • Message content (not stored at any point)
  • Usernames, display names, or profile pictures (used temporarily in memory only)
  • Email addresses or personal information
  • DMs or private channels
  • Voice data of any kind

3. How Data Is Used

All collected data is used exclusively to operate BridgeBot's features:

  • Server and channel IDs — to route relayed messages between bridges
  • Admin user IDs — to record audit log entries visible only to your server's admins
  • Message metadata — to detect and prevent message relay loops; deleted after 30 days
  • Bridge statistics — aggregated message counts per bridge, used for analytics and leaderboards

4. Data Sharing

We do not sell, rent, or share any data with third parties. Data is stored locally on our servers and is never transmitted externally.

Note: when a bridge is active, message content is relayed between two Discord servers. By creating a bridge, both server admins consent to this relay. We have no control over what the receiving server does with messages visible in their channels.

5. Data Retention

  • Message relay metadata — automatically deleted after 30 days
  • Bridge and server configuration — retained until the bridge is deleted or the bot is removed
  • Audit logs — retained indefinitely; visible only to your server's admins

When BridgeBot is removed from a server, that server's data is marked as inactive but not immediately purged, to allow rejoining without reconfiguration. You may request full deletion by contacting us.

6. Data Security

Data is stored in a private database accessible only by the bot process. We do not expose raw database access to any third party. Webhook URLs are stored securely and are only used to relay messages.

7. Your Rights

You have the right to:

  • Request deletion of your server's data by removing the bot and contacting us
  • Request a summary of what data is stored for your server
  • Export your bridge configuration at any time using /export

8. Children's Privacy

BridgeBot is not directed at children under 13. We do not knowingly collect data from users under 13. If you believe a user under 13 is using the bot, please contact us.

9. Changes to This Policy

We may update this Privacy Policy from time to time. The "last updated" date at the top reflects the most recent revision. Continued use of BridgeBot after changes constitutes acceptance.

10. Contact

For privacy requests or questions, please reach out via our Discord support server or contact the bot developer directly on Discord.
